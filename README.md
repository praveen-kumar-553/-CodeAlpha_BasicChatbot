
# CodeAlpha Basic Chatbot

## Project Description
This is a simple rule-based chatbot developed
using Python.

## Features
- Greets the user
- Responds to predefined messages
- Provides help instructions
- Handles unknown messages
- Exits when the user types bye

## Technologies Used
- Python
- Python IDLE

## Concepts Used
- Functions
- While loop
- If-elif-else statements
- User input and output
- String methods

## How to Run
1. Install Python.
2. Open main.py using Python IDLE.
3. Press F5.
4. Enter a message in the Python Shell.
5. Type bye to exit.

## Conclusion
This project demonstrates the basic working
of a rule-based chatbot using Python.
